TUBE: Tangent Upper Bound on Evidence
for Discrete Diffusion Language Models

TUBE is a tractable upper bound on the (intractable) marginal log-likelihood: together with the ELBO it localizes the true value, $\;\mathrm{ELBO}(x)\le \log p(x)\le \mathrm{TUBE}_\psi(x)$.

Abstract

Log-likelihood is the standard metric for evaluating generative models, but it is intractable for discrete (masked) diffusion language models (MDMs / any-order ARMs), whose likelihood marginalizes over all latent generation orders. Existing evaluations rely on the ELBO, a lower bound that leaves the gap to the true log-likelihood unknown and blocks a rigorous comparison with autoregressive baselines.

We introduce the Tangent Upper Bound on Evidence (TUBE): using the concavity of $\log$ and a first-order (tangent) majorization around a tractable surrogate $\psi(x)$, we obtain a valid upper bound $\;\mathrm{TUBE}_\psi(x)=\log\psi(x)+\frac{p_{\mathrm{model}}(x)-\psi(x)}{\psi(x)}$, with equality iff $\psi=p_{\mathrm{model}}$. Crucially, TUBE is linear in the model likelihood, so it admits an unbiased, bound-preserving Monte-Carlo estimator — unlike CUBO / TVO / IS-VG-B, whose finite-sample estimators break the bound.

Combined with the ELBO, TUBE two-sidedly localizes the true likelihood, $\;\mathrm{ELBO}(x)\le\log p(x)\le\mathrm{TUBE}_\psi(x)$. Applied to block MDMs / AO-ARMs, it reveals that these models remain strictly below the exact autoregressive baseline in likelihood.

Tangent Upper Bound

From the tangent majorization $\log a \le \log b + \frac{a-b}{b}$ with $a=p_{\mathrm{model}}(x)$, $b=\psi(x)$:

$\displaystyle \mathrm{TUBE}_\psi(x) \;:=\; \log\psi(x) + \frac{p_{\mathrm{model}}(x)-\psi(x)}{\psi(x)}, \qquad \mathrm{ELBO}(x)\le\log p(x)\le\mathrm{TUBE}_\psi(x).$

The bound is tightest when the surrogate is close to the model, $\psi(x)\approx p_{\mathrm{model}}(x)$; a self-surrogate from $M$ sampled generation orders gets tighter as $M$ grows.

Results

On OpenWebText / LM1B with block diffusion (block sizes $L'\in\{4,8,16\}$), TUBE is the only bound-preserving upper estimator in the comparison — CUBO, TVO and IS-VG-B frequently violate $\mathrm{ELBO}_K$ at finite sample size. Across all block sizes and generation regimes, AO-ARM / MDM perplexity stays above the exact AR baseline.
